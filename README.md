# BruceNEKO-s-Project
这是一个可以通过LCD1602液晶显示屏显示CPU/GPU温度和实时占用的程序
下载pico-lcd-monitor.zip解压到文件夹，并按照文件夹内的接线方式接线
双击.bat文件即可运行

This is a program that can display CPU/GPU temperature and real-time usage on an LCD1602 screen. 
Download pico-lcd-monitor.zip, unzip it into a folder, and connect the wires according to the wiring diagram in the folder. 
Double-click the .bat file to run it.
